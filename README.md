# 📡 Aprendendo Protocolos HTTP na Prática

Este repositório contém um exemplo educativo para demonstrar como os 
protocolos HTTP funcionam na prática, usando HTML, CSS e JavaScript puro.

## 🎯 Objetivo de aprendizado

- Entender o modelo Cliente-Servidor
- Diferenciar os métodos HTTP (GET e POST)
- Visualizar requisições e respostas em tempo real
- Interpretar status HTTP (200, 404, 500)
- Compreender o papel dos cabeçalhos e corpo da mensagem

## 🚀 Funcionalidades

| Botão | Método | O que faz |
|-------|--------|-----------|
| ENVIAR | POST | Envia título e conteúdo para o servidor |
| BUSCAR | GET | Busca os últimos posts da API |
| LIMPAR LOG | - | Limpa o monitor de requisições |

## 🧪 Como testar

1. Baixe ou clone este repositório
2. Abra o arquivo `index.html` no navegador
3. Preencha os campos e clique em "ENVIAR"
4. Observe o log das requisições
5. Aperte F12 > aba "Network" para ver os detalhes técnicos

## 🛠️ Tecnologias utilizadas

- HTML5 semântico
- CSS3 (Flexbox, design responsivo)
- JavaScript ES6+ (async/await, Fetch API)
